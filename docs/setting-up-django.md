# Setting Up Django

Read the first part of the django guide: https://docs.djangoproject.com/en/6.0/intro/install/

once you have it setup then all you have to do is clone the github repo which means all you have to do is run this command in the terminal.

`git clone git@github.com:woawaleksander/election-site.git`

then to run the website locally you just run this command

`python manager.py runserver`

The Django guide should also explain this too alongside how to use it.
