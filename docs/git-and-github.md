# Understanding GitHub and Git

So Git is a version control system. It allows you to track every version (or commit) of a repository (the project) in order to help recover older versions of a project in case you fucked up.

GitHub is what we call a Git Forge. It's essentially just a platform that provides a space to post your projects and have others work on them. Rather than using the git tool in the command line you can just use the interface.

The easiest way to push changes to GitHub is by using the built in tool in Visual Studio Code (VSCode) or with GitHub Desktop.
